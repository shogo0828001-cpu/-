# フリーランスエンジニア集客プラットフォーム

フリーランスのソフトウェアエンジニアを集客し、クライアント企業とマッチングするためのプラットフォームです。

## 特徴

✅ **エンジニアプロフィール管理**
- スキル・経験年数・専門分野の登録
- ポートフォリオ・GitHub連携
- 時給単価の設定

✅ **マッチング機能**
- クライアント企業からの案件検索・応募
- エンジニアのスキル条件にマッチした案件推薦
- 評価・レビューシステム

✅ **案件管理**
- 企業からの案件投稿
- 詳細な要件設定
- 応募者管理

✅ **チャットシステム**
- エンジニアとクライアント間のダイレクトメッセージ
- 案件詳細の相談

## インストール

```bash
# 依存パッケージをインストール
pip install -r requirements.txt

# データベース初期化
python -m alembic upgrade head
```

## 使い方

### アプリを起動

```bash
uvicorn main:app --reload
```

ブラウザで `http://localhost:8000` を開く

## 主な機能

### エンジニア向け
- プロフィール作成・編集
- スキル登録
- 案件検索・応募
- マイページ・応募履歴管理

### クライアント向け
- 案件投稿
- エンジニア検索・スカウト
- 応募者管理
- 契約・請求管理

## 技術スタック

- **バックエンド**: FastAPI
- **フロントエンド**: HTML5 + CSS3 + JavaScript
- **データベース**: SQLite/PostgreSQL
- **認証**: JWT

## データベーススキーマ

- Users（ユーザー）
- Engineers（エンジニア詳細情報）
- Companies（企業情報）
- Jobs（案件）
- Applications（応募）
- Reviews（評価）
- Messages（メッセージ）
